#WRITING_SKILLS_GUIDE .md

## Default Stack

For fiction writing:

**Character Canon**
→ **Novel Continuation** when continuing existing story
→ **Story Reasoning & Narrative Control**
→ **Optional Scene Skill**
→ **Final Prose**

## Skill Roles

- **Character Canon** — Who are these characters?
- **Novel Continuation** — Where is the story now?
- **Story Reasoning** — What is worth writing next?
- **Immersive Tension** — How should an important interaction feel?
- **Sex Scene Narrative** — How does sexual intimacy function within the story?
- **Orgasm-Control Narrative** — How does this specific control mechanic work?
- **Blind-Box Discovery** — What new possibility should be explored when the user asks for surprise?

## Selection

Do not load every optional skill automatically.

### Normal story
Character Canon + Story Reasoning

### Continuation
Character Canon + Novel Continuation + Story Reasoning

### High-tension interaction
Add Immersive Tension.

### Sexual scene
Add Sex Scene Narrative.

### Specific orgasm-control scenario
Add Orgasm-Control Narrative.

### Open-ended / surprise prompt
Add Blind-Box Discovery.

## Priority

**Character Canon
> Established Story Facts
> Current Character & Relationship State
> Story Reasoning
> Scene-Specific Skills
> Genre Tropes**

## Rules

- One core rule should have one primary owner.
- Do not repeat the same instruction across multiple skills.
- Skills are selective tools, not mandatory checklists.
- Stop applying a technique once its narrative purpose is fulfilled.
- Examples in skills are illustrative, never exhaustive.
- Research and invention may expand beyond the user's existing examples when relevant.
- Perform routing and reasoning silently; output the story unless analysis is requested.

## Principle

**Canon defines the characters.  
Continuity defines their current state.  
Reasoning decides what matters next.  
Scene skills shape presentation.  
Discovery expands possibilities.**
